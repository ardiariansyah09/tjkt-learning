MATERI 01

Pengalamatan IPv6 Dasar

Alamat 128 bit, penyingkatan, prefix, link-local, multicast, dan pengantar dual stack.

Tujuan Pembelajaran

Membaca alamat IPv6, mengenali lingkup alamat, dan memahami dual stack.

128 bit dan heksadesimal

IPv6 menggunakan alamat 128 bit yang ditulis dalam delapan kelompok heksadesimal 16 bit. Contoh dokumentasi: 2001:db8:0:1:0:0:0:10. Nol di awal kelompok boleh dihapus; satu rangkaian kelompok nol boleh diganti :: hanya sekali dalam satu alamat. Contoh tersebut dapat disingkat menjadi 2001:db8:0:1::10. Prefix /64 menyatakan 64 bit pertama sebagai bagian prefix.

Lingkup dan jenis alamat

Alamat link-local berada pada fe80::/10 dan digunakan pada satu link; router tidak meneruskannya ke link lain. Alamat multicast menggunakan ff00::/8. IPv6 tidak menggunakan broadcast. ::1 adalah loopback, sedangkan :: merupakan alamat unspecified. 2001:db8::/32 dicadangkan untuk dokumentasi, sehingga contoh ini bukan alokasi Internet untuk sekolah.

Konfigurasi dan transisi

Neighbor Discovery menggunakan ICMPv6 untuk menemukan tetangga dan router; jangan menyamakannya dengan ARP IPv4. Host dapat memperoleh konfigurasi melalui SLAAC dan/atau DHCPv6 sesuai rancangan; informasi default router dipelajari melalui Router Advertisement. Dual stack menjalankan IPv4 dan IPv6 berdampingan. Uji alamat lokal sebelum tujuan jauh dan periksa rute serta DNS AAAA. Ketiadaan NAT tidak menghilangkan kebutuhan firewall.

Latihan Penerapan

Uraikan 2001:db8:0:1::10 menjadi delapan kelompok: 2001:0db8:0000:0001:0000:0000:0000:0010. Kelompokkan ::1, fe80::1, dan ff02::1 sebagai loopback, link-local unicast, dan multicast. Pada lab dual stack berizin, catat alamat, prefix, rute default, dan hasil ping IPv4/IPv6. Perintah berbeda antar-OS; gunakan bantuan sistem yang tersedia.
