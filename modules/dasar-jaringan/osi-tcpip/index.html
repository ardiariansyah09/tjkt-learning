MATERI 01

Model OSI dan TCP/IP

Pelajari tujuh lapisan OSI, pemetaan TCP/IP, enkapsulasi data, dan game susun protokol interaktif.

Tujuan Pembelajaran

  • Menjelaskan tujuh lapisan OSI dan empat lapisan TCP/IP.
  • Memetakan fungsi protokol dan mengurutkan enkapsulasi/dekapsulasi.
  • Menggunakan model berlapis untuk menentukan pemeriksaan gangguan.

Mengenal Model Berlapis

Aplikasi, transport, pengalamatan, framing, dan media memiliki tugas berbeda dalam komunikasi. Model berlapis membantu mempelajari fungsi serta menelusuri gangguan secara teratur. Model ini bukan daftar perangkat yang harus dipisah secara fisik.

Aplikasi pengirim

Membuat data.

Protokol dan media

Mengatur serta membawa data.

Aplikasi penerima

Menggunakan data.

Contoh: koneksi kabel aktif tetapi halaman web gagal terbuka. Telusuri pengalamatan, DNS, transport, dan layanan; jangan langsung menyimpulkan kabel rusak.

Istilah PDU bergantung protokol dan konteks. Pemetaan fungsi tidak selalu berarti implementasi memiliki batas yang terpisah persis seperti diagram OSI.

TCP/IP mengelompokkan fungsi komunikasi Internet. Pemetaan terhadap OSI merupakan pendekatan belajar, bukan aturan pemisahan komponen perangkat lunak.

Enkapsulasi dan Dekapsulasi

Pengirim menambahkan informasi protokol ketika data bergerak menuju media: data aplikasi → segmen TCP/datagram UDP → paket IP → frame → bit/sinyal. Penerima memproses informasi tersebut dalam arah sebaliknya.

Port membantu mengidentifikasi endpoint transport, IP membantu pengalamatan antarmuka dan routing, sedangkan MAC Ethernet digunakan pada link lokal. Router memproses paket lalu membentuk frame baru untuk link berikutnya; alamat MAC tidak sekadar dibawa tanpa perubahan sepanjang Internet.

Latihan: jelaskan perbedaan fungsi port, IP, dan MAC saat browser mengakses server di jaringan lain.

Simulator Perjalanan Paket

Pilih permintaan web atau DNS, lalu ikuti langkah penambahan dan pelepasan informasi protokol. Simulasi menyederhanakan proses dan tidak mengirim paket nyata.

Pengirim

    Penerima

      Layer Link-Up: Susun Protokol

      Pilih kartu protokol atau fungsi, lalu pilih lapisan yang paling sesuai. Perhatikan bahwa pemetaan adalah model pembelajaran.

      Rangkuman

      • Model berlapis memisahkan pembahasan fungsi komunikasi.
      • IP, MAC, dan port berperan pada konteks berbeda.
      • Enkapsulasi menambahkan informasi protokol; dekapsulasi memprosesnya pada penerima.
      • Gunakan bukti saat menelusuri gangguan, bukan hanya nama lapisan.

      Posttest OSI dan TCP/IP

      Jawab seluruh soal. Nilai minimum kelulusan 80; pelajari kembali materi jika belum mencapai batas.
