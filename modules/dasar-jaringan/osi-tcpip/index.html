KONSEP DASAR

Mengapa Komunikasi Jaringan Dibagi Menjadi Lapisan?

Komunikasi jaringan melibatkan banyak fungsi: aplikasi membuat data, protokol mengatur komunikasi antaraplikasi, alamat membantu menentukan tujuan, dan media membawa sinyal. Model berlapis membantu kita mempelajari serta menelusuri fungsi-fungsi itu secara teratur.

02 · SUITE PROTOKOL INTERNET

Model TCP/IP dan pemetaannya

Model TCP/IP mengelompokkan fungsi komunikasi Internet menjadi lebih sedikit lapisan. Pemetaan terhadap OSI berguna sebagai pendekatan belajar, bukan aturan bahwa semua implementasi harus mempunyai batas yang identik.

Model TCP/IPLapisan OSI yang sering dipetakanContoh fungsi / protokol
AplikasiOSI 7, 6, dan 5HTTP, DNS, SSH, TLS; layanan dan data aplikasi
TransportOSI 4TCP, UDP; komunikasi antaraplikasi
InternetOSI 3IP; pengalamatan dan penerusan paket
Akses JaringanOSI 2 dan 1Ethernet, Wi-Fi, framing, dan media fisik
Catatan istilah: beberapa buku menggunakan nama “Link” atau “Network Access” dan dapat membagi lapisan bawah dengan cara berbeda. Ikuti model yang ditetapkan pada materi atau standar yang sedang dipelajari.
03 · PERJALANAN DATA

Enkapsulasi dan dekapsulasi

Ketika aplikasi mengirim data, setiap lapisan pengirim menggunakan informasi yang relevan untuk menyiapkan data bagi lapisan berikutnya. Di penerima, informasi itu diproses kembali sesuai fungsi lapisannya.

1Aplikasi menghasilkan data

Contoh: permintaan halaman web.

2Transport menyiapkan komunikasi

Port dan informasi transport membentuk segmen TCP atau datagram UDP.

3Internet memberi informasi IP

Informasi alamat IP digunakan untuk penerusan paket.

4Link membuat frame

Alamat link dan informasi pemeriksaan frame digunakan pada satu link.

5Fisik mengirim sinyal

Bit direpresentasikan sebagai sinyal melalui media yang dipilih.

Nama umum perjalanan PDU adalah data → segmen/datagram → paket → frame → bit. Perangkat perantara memproses informasi sesuai perannya; router, misalnya, meneruskan paket IP dan membentuk ulang frame untuk link berikutnya.

      04 · REFLEKSI

      Rangkuman

      • OSI menyediakan tujuh lapisan untuk menjelaskan fungsi komunikasi jaringan.
      • TCP/IP mengelompokkan fungsi menjadi lapisan aplikasi, transport, internet, dan akses jaringan.
      • Enkapsulasi menambahkan informasi sesuai kebutuhan lapisan; penerima memprosesnya kembali.
      • Model berlapis membantu mengarahkan pemeriksaan, tetapi gejala yang sama dapat memiliki penyebab di lapisan berbeda.
